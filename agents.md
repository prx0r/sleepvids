# agents.md — Important Rules for AI Agents

## CRITICAL: Read generationguide.md first

Before doing ANYTHING with YouTube channels, uploads, or monetization, read `/root/sleepvids/generationguide.md`. It contains:

- Channel setup (Brand Accounts, AdSense rules)
- AI slop crackdown rules (2026 enforcement)
- What separates survivors from dead channels
- Our compliance strategy
- Differentiation rules
- Receipts to keep

## Key flags

- **ONE AdSense per person.** Duplicates get banned. No exceptions.
- **"Related channels" is the real risk.** Not email separation. AdSense + device fingerprints link everything.
- **Same voice + same template = death.** Differentiate per channel.
- **Keep receipts.** /sections/, /RESEARCH.md, /STORYBOARD.md prove human authorship.
- **NoSlop is compliance.** The quality gate catches the patterns that get channels killed.
- **Appeals work** but take weeks. Prevention is better.
- **Faceless is a style, not a crime** — but only with genuine transformation and real scripts.

## Per-session checklist

1. Run NoSlop on every draft before considering it done
2. Verify different voice/visual per channel
3. Check for cross-posting (none allowed)
4. Ensure project files exist as receipts
5. Review generationguide.md before any upload decision
